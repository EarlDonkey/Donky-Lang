Donky: The compiled language built for speed and scale.

Donky compiles straight to native machine code through Cranelift, with NaN-boxed values and a garbage-collected runtime. Sockets, JSON, hashing and FFI are built in, so a real server is a few lines long.

Why Donky

      
Built to run fast and stay simple.

      
One compiler, one small runtime, one executable out.

      

        
Native code, not an interpreter
Donky lowers to Cranelift IR and emits an object file that links into a standalone .exe. Builtin calls and operators are direct native calls.

        
Compact value model
Every value is one 64-bit NaN-boxed word. Numbers need no allocation, and strings, arrays and maps are garbage collected.

        
Batteries in the runtime
TCP sockets, HTTP client, JSON encode/decode, MD5/SHA-1/SHA-256/HMAC, time, and a worker-thread pool via spawn.

        
Math for numerical work
pow, exp, log, tanh, max, min and abs are builtins. The bundled micrograd engine trains a small neural net entirely in Donky.

        
Catchable errors
try / catch / throw work across call boundaries. Type errors, division by zero and bad indexes throw instead of corrupting state.

        
FFI when you need it
Load a DLL, resolve a symbol, call it. ffi_alloc, ffi_peek and ffi_poke cover raw memory.
